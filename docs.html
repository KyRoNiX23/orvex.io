Welcome to Orvex

Orvex is an independent voxel sandbox project. The goal is to build an extensible world with procedural generation, dynamic environment systems and a hybrid modding architecture.

This documentation is an initial project guide. Some features are planned or under development; it is not a promise that every system is already available.

Project status

Development is ongoing. For the most accurate implementation status, check the source code, repository issues and latest commits.

Architecture direction

The project is organized around separate gameplay and engine systems. The intention is to keep responsibilities clear and allow new features to be integrated without tightly coupling every component.

  • World and chunk generation
  • Environment and time simulation
  • Runtime systems and game logic
  • Mod loading and extension points

Mods system

Orvex is being developed with a hybrid modding approach. The exact API, compatibility rules and packaging format should be considered evolving until documented in the source repository.

Contributing

Before submitting a change, read the repository's CONTRIBUTING.md and follow the existing project conventions.
